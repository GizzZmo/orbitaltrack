# Assets

Screenshots and visual assets for the OrbitalTrack README and documentation.

## Files

| File                  | Description                                      |
|-----------------------|--------------------------------------------------|
| `main-view.jpg`       | Full-screen 3D globe with HUD and satellite points |
| `telemetry-panel.jpg` | Live telemetry panel for a selected satellite    |
| `orbit-path.jpg`      | Selected satellite with orbital path and ground track |

## Usage

These images are referenced from the root `README.md`.  
To update screenshots, replace the files and keep the same names so the README links continue to work.
